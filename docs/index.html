Aveiro em Movimento

Uma API sobre os sensores de Aveiro, para qualquer entidade construir serviços com os dados da cidade. Estas duas páginas são exemplos do que se faz com ela.

  • Onde estaciono em Aveiro?O parque com lugares livres mais perto do destino, à hora de chegada.
  • Visitar Aveiro com menos genteA ordem de visita que apanha cada local turístico longe do seu pico.

Aqui as páginas funcionam sem a API: os dados vêm embutidos em cada uma e são os da semana de 3 a 10 de novembro de 2026, medidos pelos sensores do Aveiro Tech City Living Lab. Mostram como foi essa semana, não o que se passa neste momento. O código da API e destas páginas está em github.com/androidrian/aveiro-em-movimento.
